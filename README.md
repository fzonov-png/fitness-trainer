# Fitness Trainer

Домашняя программа тренировок для мужчины 41 года: утром — только гребной тренажёр 30–40 минут; вечером Пн/Ср/Пт — растяжка на шпагат и мобильность тазобедренных суставов, Вт/Чт/Сб — силовая 60–90 минут; воскресенье — выходной. Гири 16/24 кг, гантели, турник, собственный вес и тренажёр для растяжки. Тренировки в зале в приложение не входят — это отдельная нагрузка.

Приложение — один статический сайт. Открывается по ссылке в телефоне, ставится на домашний экран, работает офлайн. Прогресс хранится в телефоне (localStorage) и выгружается в JSON.

## Что внутри

- **12-недельный цикл**: 3 блока по 4 недели, каждая 4-я неделя — разгрузка.
- **2 домашние тренировки в день**: 05:30 и 21:20, кроме воскресенья.
- **Утро — только гребля 30–40 минут**: Z2, интервалы, темповая работа, ступенчатый темп и тест 500 м.
- **Вечер Пн/Ср/Пт — только шпагат и мобильность бёдер**: продольный и поперечный шпагат, приводящие, сгибатели бедра, ягодичные, 90/90.
- **Вечер Вт/Чт/Сб — силовая 60–90 минут**: гиря, гантели, турник, собственный вес.
- **Воскресенье — выходной**.
- **Собственный вес в силовые дни** — отжимания, подтягивания, обратные выпады, ягодичный мост, «супермен», планки, скручивания и ротации корпуса. Отдельные уровни прогрессии — в «Гиде».
- **Прогрессия**: RPE, правило двух тренировок, рост повторов/веса, увеличение удержаний в растяжке, PNF с 5-й недели, активная гибкость с 9-й.
- **Дневник**: отметки упражнений, рабочий вес, повторы, минуты, метры, RPE, заметки.
- **Прогресс**: вес и талия с графиком, ИМТ при каждом взвешивании, % выполнения по неделям, серия дней, тесты (подтягивания, отжимания, 500 м, планка, жим 24 кг).
- **Вес каждый день**: поле «Вес сегодня» на главном экране, автоматический расчёт ИМТ, история последних взвешиваний с ИМТ.
- **Готовность**: сон, энергия, крепатура, стресс → подсказка, снижать ли нагрузку.
- **Питание**: калькулятор ккал и БЖУ, пример дня, спортпит, правила дефицита.
- **Библиотека упражнений**: техника, ошибки, упрощения и усложнения; отдельная группа «Собственный вес».
- **Главный экран**: приветствие «Привет, Федор!!!», готовность, вес и две тренировки дня.
- **Питание на каждый день**: калории и БЖУ под текущий вес, меню по времени: завтрак 06:00–06:30, обед, перекус, ужин и еда после вечерней; варианты для силового, аэробного дня и выходного.
- **Спортпит**: время, доза, назначение и предостережения по креатину, протеину, кофеину, D3, омеге-3, магнию и электролитам.
- **Таймер упражнения**: кнопка «⏱ Таймер: старт» у каждого упражнения. Считает время выполнения, отдых между подходами и отдых между упражнениями, подаёт звук и вибрацию, автоматически отмечает упражнение после последнего подхода.
- **Bluetooth-треначок (FTMS)**: подключение к треначку с сервисом Fitness Machine (беговая дорожка, гребной тренажёр, велотренажёр) по Web Bluetooth; целевая скорость (0.01 км/ч), наклон (0.1 %) и сопротивление; живые метрики (скорость, наклон, дистанция, время, энергия, пульс, темп, мощность, каденс); старт/пауза/стоп; результат автоматически сохраняется в историю треначка и в дневник на «Сегодня».
- **Ручной ввод результата**: если Bluetooth не подключился (например, на iPhone), результат записывается вручную (время + дистанция).
- **PWA**: установка на домашний экран, офлайн-кеш, таймер отдыха со звуком.

## Публикация на GitHub Pages

### Вариант 1 — через сайт GitHub (без команд)

1. Создай новый публичный репозиторий, например `fitness-trainer`.
2. Загрузи все файлы из этой папки в **корень** репозитория (Add file → Upload files).
3. Открой **Settings → Pages**.
4. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)**. Сохрани.
5. Через 1–2 минуты сайт будет доступен:

```
https://fzonov-png.github.io/fitness-trainer/
```

> GitHub Pages для приватных репозиториев требует платный план. Если не хочешь публичный код — используй публичный репозиторий без личных данных в файлах (их там и нет: вес и дневник хранятся только в телефоне).

### Вариант 2 — через git

```bash
cd fitness-trainer
git init
git add .
git commit -m "Fitness Trainer: программа тренировок"
git branch -M main
git remote add origin https://github.com/fzonov-png/fitness-trainer.git
git push -u origin main
```

Дальше включи Pages в **Settings → Pages** (branch `main`, folder `/`).

### Вариант 3 — GitHub CLI

```bash
cd fitness-trainer

gh repo create fitness-trainer --public --source=. --push
gh api -X POST repos/fzonov-png/fitness-trainer/pages \
```

## Нативная iOS-обёртка (Capacitor + CoreBluetooth) — чтобы Bluetooth-треначок работал на iPhone

Web Bluetooth в iOS (Safari / WebKit) **не реализован**, поэтому для полноценной работы на iPhone нужна нативная обёртка.

Что уже сделано в коде:

- `treadmill.js` определяет нативный путь: `tmSupportedNative()` (Capacitor → плагин `TreadmillBle`) → `tmConnect`, `tmApply`, `tmStart/Pause/Stop`, `tmDisconnect`, слушатель событий `metrics`;
- нативный путь приоритетнее Web Bluetooth; если Capacitor-плагин недоступен — приложение падает на Web Bluetooth (Android/Chrome) или ручной ввод (iOS Safari).

Исходники нативной стороны:

- `ios/App/App/Plugins/TreadmillBle/TreadmillBlePlugin.swift` — Capacitor-плагин на CoreBluetooth: скан/подключение к FTMS (0x1826), Treadmill Data (0x2ACD) / Rower (0x2AD1) / Indoor Bike (0x2AD2) / Cross Trainer (0x2ACE), Control Point (0x2AD9), события `metrics`;
- `ios/App/capacitor.config.json`, `ios/App/App/Info.plist` (NSBluetoothAlwaysUsageDescription / NSBluetoothPeripheralUsageDescription), `ios/App/App/AppDelegate.swift`;
- `ios/BUILD_TEMPLATE/` — шаблон для копирования в Xcode-проект;
- `docs/ios-build.md` — пошаговая документация по сборке.

Дальше (на Mac с Xcode):

```bash
npm i @capacitor/cli @capacitor/core @capacitor/ios
npx cap add ios
npx cap sync ios
npx cap open ios
```

и в Xcode собрать Runner с подключённым плагином TreadmillBle.

Сборка требует macOS + Xcode; сам репозиторий редактируется здесь на Windows, поэтому Xcode-проект (`ios/App/App/Runner.xcodeproj`) создаётся нативно через Capacitor и не храним вручную.

## Установка на телефон

- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран Домой».
- **Android (Chrome):** открыть ссылку → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

После установки приложение открывается без адресной строки и работает без интернета (после первого запуска).

## Данные и резервные копии

- Дневник, вес, тесты и настройки хранятся **в браузере телефона** (localStorage). Между устройствами автоматически не синхронизируются.
- Раз в месяц: **Прогресс → Настройки → Экспорт данных**. Получишь JSON.
- Новый телефон или очистка браузера: открой сайт → **Импорт** → выбери JSON.
- Если очистить данные сайта в настройках браузера, прогресс удалится. Экспорт — единственная страховка.

## Как менять программу

- Упражнения и недельные параметры — в `program.js` (массивы `P` и `LOAD`, функции тренировок).
- Тексты питания и рекомендаций — в `views-guide.js`.
- После правок обнови версию кеша в `sw.js`: `const CACHE = 't41-v14';` — иначе телефон покажет старую версию. Каждый деплой — новая версия.
- Проверка локально: в папке выполнить `python -m http.server 8000` и открыть `http://localhost:8000`.

## Расписание (по умолчанию)

| День | 05:30 | 21:20 |
|---|---|---|
| Пн | Гребля Z2 | Шпагат: продольный + мобильность бёдер |
| Вт | Гребля: интервалы | Сила A: ноги + жимы |
| Ср | Гребля: темповая работа | Шпагат: поперечный + мобильность бёдер |
| Чт | Гребля: ступенчатый темп | Сила B: тяга + плечи |
| Пт | Гребля: короткие интервалы | Шпагат: полный комплекс |
| Сб | Длинная гребля Z2 | Сила C: полное тело + мощность |
| Вс | Выходной | Выходной |

Утро — 30–40 минут, только гребной тренажёр. Вечерняя растяжка — 40–45 минут, только шпагат и мобильность бёдер. Силовые — 60–85 минут. Недели 4, 8, 12 — разгрузка (−40% объёма). Тесты — недели 1, 6, 12.

## Питание (кратко)

Для 183 см / 93 кг / 41 год при активности «2 тренировки в день»:

- обмен ≈ 1874 ккал, расход ≈ 3279 ккал;
- цель −20% ≈ **2620 ккал**;
- белок **175 г**, жиры **85 г**, углеводы **290 г**, вода **3,3 л**;
- темп снижения 0,5–0,7 кг в неделю, ориентир к концу цикла — 85–86 кг.

Добавки с доказательной базой: креатин 5 г/день, протеин при недоборе белка, витамин D3 по анализу, омега-3, кофеин до 14:00, магний при необходимости. «Бустеры тестостерона» и жиросжигатели не нужны.

Калькулятор в приложении пересчитывает всё под фактический вес и выбранную активность/дефицит.

## Важно

Программа не заменяет врача и тренера. При боли в груди, головокружении, нехватке дыхания — остановиться. Боль в суставах больше 3/10 — заменить упражнение. В 41 год и при ИМТ 27,8 на старте раз в год стоит проверять давление, липиды, глюкозу/HbA1c, креатинин, витамин D.
