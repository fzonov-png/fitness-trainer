# Fitness Trainer

Домашняя программа тренировок для мужчины 41 года: две тренировки в день, гребля, гири 16/24 кг, гантели, турник, собственный вес и тренажёр для растяжки. Тренировки в зале в приложение не входят — это отдельная нагрузка, а вечера понедельника, среды и пятницы здесь намеренно лёгкие.

Приложение — один статический сайт. Открывается по ссылке в телефоне, ставится на домашний экран, работает офлайн. Прогресс хранится в телефоне (localStorage) и выгружается в JSON.

## Что внутри

- **12-недельный цикл**: 3 блока по 4 недели, каждая 4-я неделя — разгрузка.
- **2 домашние тренировки в день**: 05:30 и 21:20.
- **Вечер**: растяжка (вт/ср/чт/сб) или восстановление (пн/пт), воскресенье — отдых.
- **Сила** — вторник, четверг, суббота утром (гиря, гантели, турник, собственный вес).
- **Собственный вес каждый день** — отжимания, подтягивания, приседания, обратные выпады, ягодичный мост, «супермен», планки, скручивания, ротации корпуса и hollow hold. Отдельные уровни прогрессии — в «Гиде».
- **Гребля** — аэробная база, интервалы, темповая работа, тест 500 м.
- **Растяжка для единоборств** — отдельные вечерние блоки: продольный и поперечный шпагат, приводящие, сгибатели бедра, грудной отдел, плечи, шея, кисти, стопы.
- **Прогрессия**: RPE, правило двух тренировок, рост повторов/веса, PNF-растяжка с 5-й недели, активная гибкость с 9-й.
- **Дневник**: отметки упражнений, рабочий вес, повторы, минуты, метры, RPE, заметки.
- **Прогресс**: вес и талия с графиком, ИМТ при каждом взвешивании, % выполнения по неделям, серия дней, тесты (подтягивания, отжимания, 500 м, планка, жим 24 кг).
- **Вес каждый день**: поле «Вес сегодня» на главном экране, автоматический расчёт ИМТ, история последних взвешиваний с ИМТ.
- **Готовность**: сон, энергия, крепатура, стресс → подсказка, снижать ли нагрузку.
- **Питание**: калькулятор ккал и БЖУ, пример дня, спортпит, правила дефицита.
- **Библиотека упражнений**: техника, ошибки, упрощения и усложнения; отдельная группа «Собственный вес».
- **Главный экран**: приветствие «Привет, Федор!!!», готовность, вес и две тренировки дня.
- **PWA**: установка на домашний экран, офлайн-кеш, таймер отдыха со звуком.

## Публикация на GitHub Pages

### Вариант 1 — через сайт GitHub (без команд)

1. Создай новый публичный репозиторий, например `fitness-trainer`.
2. Загрузи все файлы из этой папки в **корень** репозитория (Add file → Upload files).
3. Открой **Settings → Pages**.
4. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)**. Сохрани.
5. Через 1–2 минуты сайт будет доступен:

```
https://fzonov-png.github.io/fitness-trainer/
```

> GitHub Pages для приватных репозиториев требует платный план. Если не хочешь публичный код — используй публичный репозиторий без личных данных в файлах (их там и нет: вес и дневник хранятся только в телефоне).

### Вариант 2 — через git

```bash
cd fitness-trainer
git init
git add .
git commit -m "Fitness Trainer: программа тренировок"
git branch -M main
git remote add origin https://github.com/fzonov-png/fitness-trainer.git
git push -u origin main
```

Дальше включи Pages в **Settings → Pages** (branch `main`, folder `/`).

### Вариант 3 — GitHub CLI

```bash
cd fitness-trainer
git init && git add . && git commit -m "Fitness Trainer"
gh repo create fitness-trainer --public --source=. --push
gh api -X POST repos/fzonov-png/fitness-trainer/pages \
  -f "source[branch]=main" -f "source[path]=/"
```

## Установка на телефон

- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран Домой».
- **Android (Chrome):** открыть ссылку → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

После установки приложение открывается без адресной строки и работает без интернета (после первого запуска).

## Данные и резервные копии

- Дневник, вес, тесты и настройки хранятся **в браузере телефона** (localStorage). Между устройствами автоматически не синхронизируются.
- Раз в месяц: **Прогресс → Настройки → Экспорт данных**. Получишь JSON.
- Новый телефон или очистка браузера: открой сайт → **Импорт** → выбери JSON.
- Если очистить данные сайта в настройках браузера, прогресс удалится. Экспорт — единственная страховка.

## Как менять программу

- Упражнения и недельные параметры — в `program.js` (массивы `P` и `LOAD`, функции тренировок).
- Тексты питания и рекомендаций — в `views-guide.js`.
- После правок обнови версию кеша в `sw.js`: `const CACHE = 't41-v2';` — иначе телефон покажет старую версию.
- Проверка локально: в папке выполнить `python -m http.server 8000` и открыть `http://localhost:8000`.

## Расписание (по умолчанию)

| День | 05:30 | 21:20 |
|---|---|---|
| Пн | Гребля Z2 + кор | Восстановление: мобильность + дыхание |
| Вт | Сила A: ноги + жимы | Растяжка: задняя цепь, продольный шпагат |
| Ср | Гребля: интервалы + хват | Растяжка: бёдра + грудной отдел |
| Чт | Сила B: тяга + плечи | Растяжка: приводящие, плечи, шея |
| Пт | Гребля: темп + кор | Восстановление: мобильность + дыхание |
| Сб | Сила C: мощность + комплекс | Растяжка: полный комплекс |
| Вс | Лёгкая гребля + мобильность | Отдых и разбор недели |

Недели 4, 8, 12 — разгрузка (−40% объёма). Тесты — недели 1, 6, 12.

## Питание (кратко)

Для 183 см / 93 кг / 41 год при активности «2 тренировки в день»:

- обмен ≈ 1874 ккал, расход ≈ 3279 ккал;
- цель −20% ≈ **2620 ккал**;
- белок **175 г**, жиры **85 г**, углеводы **290 г**, вода **3,3 л**;
- темп снижения 0,5–0,7 кг в неделю, ориентир к концу цикла — 85–86 кг.

Добавки с доказательной базой: креатин 5 г/день, протеин при недоборе белка, витамин D3 по анализу, омега-3, кофеин до 14:00, магний при необходимости. «Бустеры тестостерона» и жиросжигатели не нужны.

Калькулятор в приложении пересчитывает всё под фактический вес и выбранную активность/дефицит.

## Важно

Программа не заменяет врача и тренера. При боли в груди, головокружении, нехватке дыхания — остановиться. Боль в суставах больше 3/10 — заменить упражнение. В 41 год и при ИМТ 27,8 на старте раз в год стоит проверять давление, липиды, глюкозу/HbA1c, креатинин, витамин D.
